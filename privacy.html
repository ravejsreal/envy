envy privacy policy

Last updated: 11 October 2026

envy is a Discord bot. This page explains what it stores, why, and how to get rid of it. If anything here is unclear, ask in the support server.

What is stored

Discord IDs, and nothing else that identifies you. That means your user ID, the server ID, and whichever channel or role IDs a feature needs to work. No usernames, display names, email addresses, avatars, IP addresses or payment details are saved.

Those IDs are attached to:

  • invite counts per inviter, and a record of which inviter a joining member came from
  • warnings, each one holding the target's ID, the moderator's ID, a reason and a timestamp
  • the role IDs held for a member while they are jailed, so they can be given back on release
  • the ID of a booster's personal role
  • economy balances, streaks, and message and voice activity counts used for leaderboards
  • per server settings: the prefix, ticket configuration, autoresponders, blocked words, log channels

Message content

Message content is read but not kept, with one exception.

Commands, the blocked word filter, the invite link filter and the snipe command all read message text in memory and discard it. Snipes hold the last deleted or edited message for a channel in memory only, and are lost whenever the bot restarts. None of this is written to disk.

The exception is ticket transcripts. When a ticket channel is closed, the conversation in that one channel is saved as an HTML file, posted to a staff channel chosen by the server, and sent by DM to the person who opened the ticket. A server owner can turn transcripts off entirely, and any transcript can be deleted on request.

The AI feature

A server may designate one channel where the bot replies conversationally. That feature runs a self hosted language model on hardware we control. Message content from it is never sent to OpenAI, Anthropic, Google or any other third party, and no message is ever used to train or fine tune a model.

The image filter

Image attachments and image links are checked by a classifier running on the same machine as the bot. Images are not uploaded to any third party service, and nothing is retained after the check completes.

Where the data lives

Everything is stored as JSON files on a private server we operate. No third party has access to it. Nothing is sold, rented, shared or used for advertising.

Keeping it

Data is kept for as long as the bot is in your server and the feature is in use. When the bot is removed from a server, that server's data stops being used and can be deleted on request.

Getting it deleted

Ask and it is removed.

  • A server owner can request everything stored for their server be deleted.
  • Any user can request their own records and ticket transcripts be deleted.

Requests are handled in the support server. There is no charge and no requirement to give a reason.

Changes

If this policy changes, the updated date at the top changes with it. Material changes are announced in the support server.

Contact

Open a ticket in the support server, or message the bot owner on Discord.
